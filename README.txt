ONESTREET77 - WEBSITE DEMO

File utama: index.html
Logo: logo-onestreet77.png

Cara pakai:
1. Buka index.html di browser.
2. Untuk online, upload index.html + logo-onestreet77.png ke hosting (Netlify, GitHub Pages, cPanel, dll).
3. Ganti semua link https://shopee.co.id/ dengan URL toko Shopee ONESTREET77.
4. Harga dan nama produk berada di bagian const products pada index.html.
5. Gambar demo menggunakan URL gambar Pexels. Untuk toko komersial, sebaiknya gunakan foto produk sendiri atau foto yang memang Anda punya hak untuk digunakan.

Catatan: gambar Pexels pada demo bersifat ilustratif dan tidak mewakili produk yang dijual. Jangan menggunakan foto produk milik seller Shopee lain tanpa izin.
